Executive Summary

Inside Big Tech: Developer AI Usage & Engineering Output

Verified disclosures from 59 companies, from Google, Microsoft, Amazon and Meta to HubSpot, Airbnb, Uber, IBM, Bank of America and Baidu, on how internal AI adoption translated into code share, pull request throughput, modernization velocity, and workforce capacity. Every figure was checked word-for-word against the company's own words; claims found only in news reports were left out.

Core Discovery: The Bottleneck Inversion
AI is writing a fast-growing share of code. Google's AI-generated share of new code rose from >25% (Oct 2024) to 75% (Apr 2026), and Zeta Global reports 89.6% (Q2 2026). But code share is not shipping output: almost no company ties these numbers to cycle time or delivery throughput. Our reading of the evidence is that the human constraint has shifted to code review, automated testing, and architectural validation.

Operational Reality

How Engineering Work Actually Changed

Where internal AI creates immediate output dividends, and where teams hit constraints.

1. The Review Bottleneck Constraint
Faros AI telemetry from 10,000+ developers across 1,255 teams: on high-adoption teams, developers merged 98% more pull requests, but PR review time rose 91% and average PR size 154%, and there was "no significant correlation" with company-level gains (Faros AI, an engineering-analytics vendor). More code does not mean faster shipping if review does not scale.
2. Legacy Modernization Highest ROI
Amazon's largest disclosed gain came from mechanical upgrade work: Java 17 upgrades fell from ~50 developer-days to a few hours, an estimated 4,500 developer-years saved. Our interpretation (not Amazon's claim): well-specified, testable upgrade work is where AI output is easiest to verify.
3. Autonomous Slack Agents Agentic Leap
Moving from passive IDE autocomplete to asynchronous background agents (like Stripe Minions) yields >1,000 merged PRs/week at Stripe without engineers waiting on completions.
4. Who Benefits Most? Unquantified
The 2022 Copilot RCT reports heterogeneous effects that "show promise for AI pair programmers to help people transition into software development careers." No primary source in this dataset quantifies a seniority gap, so we give no number.
Strategic Takeaways

Guidelines for Engineering Leadership

Core principles for measuring and scaling internal developer AI.

Stop Tracking Lines of Code
Lines of Code is a vanity metric that incentivizes bloated repositories. Measure completed pull requests, lead time for changes, and cycle time.
Build Agent-Friendly CI/CD
AI agents fail in brittle, slow CI/CD pipelines. Fast, modular test suites allow agents to run tests and fix their own errors before requesting human review.
Automate the Migration Tax
Free your best senior engineers by delegating framework upgrades, library deprecations, and boilerplate test authoring to AI tools.
Engineers as System Architects
As AI drafts a growing share of code (from a quarter to nearly all new code, where disclosed), human engineers shift to curating specifications, evaluating security, and verifying system architecture.
